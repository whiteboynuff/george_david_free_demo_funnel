Section 01

Funnel Audit Overview

A top-level summary of what the funnel gets right, and the structural problems holding it back from converting visitors into leads.

✅ What Works

  • Clear, compelling core promise (growth without burnout)
  • Multiple free lead magnets — lowers barrier to entry
  • Consistent framework branding (4 Seasons)
  • Social proof via video testimonial
  • Newsletter as a long-term nurture channel
  • Quiz as an engagement + segmentation tool

🚨 Critical Problems

  • No clear hero CTA hierarchy — 9+ competing offers above the fold
  • Broken links (several CTAs go to /undefined)
  • Significant typos damage credibility ("Scalling", "webinnar")
  • Offer list is overwhelming — decision fatigue kills conversions
  • No trust signals early (no credentials, no stats, no proof)
  • No email capture form — all lead gen requires external hops
Section 02

Issues & Recommendations

Each issue is rated by conversion impact. Critical issues should be fixed before launch; moderate issues in the first iteration; polish items after.

🎯
Hero section has no single dominant CTA Critical

The above-the-fold area shows a heading, subheading, and immediately presents multiple competing offers. Visitors don't know what to do first. This is the #1 conversion killer — when everything is important, nothing is.

Fix: One hero CTA only — "Get My Free 4 Seasons Ebook". All other offers move to a secondary "Free Resources" section further down. Add a sub-link: "Already have it? Take the quiz →"
🔗
Multiple broken links pointing to /undefined Critical

At least 3 CTAs (including the Anti-Burnout Roadmap and two placeholder testimonial sections) link to /undefined. This completely destroys trust and is likely losing a significant percentage of clicks.

Fix: Audit every single button before launch. Replace /undefined links with either the correct URL or temporarily remove the section until it is ready. Do not publish placeholder content.
📝
Multiple spelling/grammar errors erode credibility Critical

Nav item "Scalling Stage Program" (should be Scaling), "webinnar" (webinar), "burining" (burning), "don't want ot miss" (to miss), "I drope here" (drop), "agaisnt" (against), "Inifnite" (Infinite). These are all visible without scrolling or clicking.

Fix: Run all copy through a spell-checker before launch. Consider having a native English speaker review the full page copy. Credibility-building content must be error-free.
📦
10 free offers presented simultaneously causes decision fatigue Moderate

The page lists: ebook, newsletter, system report, 21-day productivity call, quiz, 21-day challenge, survival guide, webinar, business basis guide, and anti-burnout roadmap — all as equal-weight cards in one long list. Visitors shut down when facing this many choices.

Fix: Lead with ONE offer in the hero (the ebook). Group the rest into 3 categories: "Start Here" (quiz + ebook), "Go Deeper" (survival guide, system report), "Take Action" (challenges, calls). Use a tabbed or collapsed layout to avoid visual overwhelm.
🏆
No social proof or credentials above the fold Moderate

First-time visitors have no reason to trust George David before they're asked to give an email. The testimonial video is buried at the bottom. There are no stats, no press mentions, no client counts near the hero.

Fix: Add a trust bar directly below the hero: e.g. "Trusted by 2,000+ entrepreneurs" + a one-sentence quote from Adrien Skow with a headshot. Move the video testimonial to just below the primary CTA.
📬
No inline email capture — all lead gen requires external redirects Moderate

Every single CTA sends the user away to an external SubscribePage link. Each redirect is a drop-off point. Embedding a simple email + name form directly on the hero would significantly improve conversion rates.

Fix: Embed the ebook optin form inline. At minimum, use an input field + button directly on the page that submits to the MailerLite API. Keep external links only as fallbacks.
🧭
Navigation menu is confusing and lacks visual hierarchy Polish

The nav shows "Free Four Seasons Ebook" twice (once in the nav list, once as a standalone button). The nav item "George David" is redundant with the logo. "Scalling Stage Program" typo is visible in the nav.

Fix: Simplify nav to: About | Success Stories | Resources | Coaching. Move the ebook CTA to a single gold button. The logo handles "home" — remove the duplicate nav link.
🎨
Visual design lacks brand identity — feels like a default template Polish

The page uses MailerLite's default styling with no distinct color palette, typography, or visual language that reflects the "4 seasons" concept. The seasonal metaphor — a genuinely strong brand idea — is never expressed visually.

Fix: Apply the brand system defined in this document: forest greens and warm golds representing the natural seasonal cycle. Use Cormorant Garamond for display type to convey wisdom and depth, DM Sans for body copy. Subtle seasonal motifs in section backgrounds.
📱
No mobile optimization evident in the markup Polish

The source page is built entirely on MailerLite's page builder with default responsive breakpoints. The long scroll of equal-weight offer cards is especially painful on mobile.

Fix: In the HTML rebuild, implement mobile-first breakpoints. Stack cards vertically on mobile, reduce hero font sizes, ensure CTA buttons are at least 44px tall on touch devices, and test on 375px viewport.

Section 08

Copy & Tone Guidelines

Writing rules to maintain brand consistency and correct the current issues across all copy.

✍️ Voice & Tone

  • Authoritative but warm — a wise mentor, not a hype marketer
  • Metaphor-led — lean into seasons, nature, cycles
  • Action-oriented headlines, reflective body copy
  • First person for personal sections ("During my journey...")
  • Second person for CTAs ("Get your free copy")
  • Avoid: "incredible", "amazing", "totally transform"

📋 Corrections Required

  • "Scalling Stage Program" → "Scaling Stage Program"
  • "webinnar" → "webinar" (all instances)
  • "burining out" → "burning out"
  • "don't want ot miss" → "don't want to miss"
  • "golden nuggets that I drope" → "drop"
  • "stop fighting agaisnt" → "against"
  • "Energy Isn't Inifnite" → "Infinite"
  • "breaktrhough" → "breakthrough"

🎯 Headline Formula

Use this structure for offer titles:

[Result] without [Pain]
or [Do X] so you can [Outcome]

Example: "Build Lasting Habits Without Burnout" not "21 Days Productivity Habits System A personalized productivity blueprint that you can implement the same day"

📝 Card Description Formula

Max 2 sentences per offer card:

Sentence 1: What problem it solves
Sentence 2: What the reader gains

Keep each card under 30 words. The CTA link is "Get free access →" — consistent across all free offers.

Section 09

HTML Implementation Notes

Technical considerations for rebuilding this page in clean HTML/CSS without a page builder.

⚙️
Font Loading

Load both fonts from Google Fonts. Add display=swap to avoid FOUT. Include font-weight variants 300, 400, 500, 600 for DM Sans and 400, 400italic, 500, 500italic for Cormorant Garamond.

Google Fonts URL: https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,400;0,500;0,600;1,400;1,500&family=DM+Sans:wght@300;400;500;600&display=swap
📬
Email Form Integration

The ebook form should submit to MailerLite's embed API. Use MailerLite's embedded form code or the JavaScript embed snippet available in the MailerLite dashboard under Forms → Embedded.

Approach: Style MailerLite's embedded form fields to match the spec above. Override their default styles with a targeted CSS block using the form's class name. Alternatively, use their API (https://developers.mailerlite.com) to post directly via fetch().
📱
Responsive Breakpoints

Three breakpoints cover all modern devices without over-engineering.

@media (max-width: 768px) — Tablet: reduce hero font to 38px, stack email+button vertically, 2-col grid for cards

@media (max-width: 480px) — Mobile: hero font 28px, 1-col grid, nav collapses to hamburger, padding: 20px
